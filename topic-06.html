Pratyek Sub-Topic — 5 Points

SPOF — Single Point of Failure

PointMahiti
Kay aahe?Ekach component gela tar sagla band.
Main GoalSPOF shodhun kadhne.
Ka use karaycha?Ekavar avalambun rahile tar risk.
Kasa kaam karto?Pratyek goshtila replica thevtat.
Kuthe use hoto?LB, DB, Cache — saglyanna replica.

Failover

PointMahiti
Kay aahe?Ek gela tar dusra lagech kaam gheto.
Main GoalDowntime kami.
Ka use karaycha?Manual la vel lagto.
Kasa kaam karto?Active-Active = donhi chalu. Active-Passive = ek rakheev.
Kuthe use hoto?Multi-AZ / Multi-region.

Retry + Exponential Backoff

PointMahiti
Kay aahe?Fail zala tar thodya velane parat.
Main GoalTemporary fail varun savarne.
Ka use karaycha?Lagech parat kele tar ajun load.
Kasa kaam karto?1s, 2s, 4s... + Jitter (thoda random).
Kuthe use hoto?Payment gateway, downstream call.

Circuit Breaker

PointMahiti
Kay aahe?Fail honarya service la kahi vel thambavne.
Main GoalEk fail zala tar sagla fail hou naye.
Ka use karaycha?Parat parat call kele tar ajun bighadto.
Kasa kaam karto?Fail jast zale → Circuit OPEN → thodya velane HALF-OPEN test.
Kuthe use hoto?Downstream service fail.

Bulkhead

PointMahiti
Kay aahe?Ek bhagacha fail dusryala lagoo deu naka.
Main GoalIsolation.
Ka use karaycha?Ek queue bharli tar sagla thambla.
Kasa kaam karto?Veglya thread-pool / vegli maryada.
Kuthe use hoto?Payment vs Notification vegle.

Monitoring — Logs / Metrics / Tracing

PointMahiti
Kay aahe?Kay chalay he baghne.
Main GoalProblem aadhi kalne.
Ka use karaycha?Kalale nahi tar durust karta yet nahi.
Kasa kaam karto?Logs = kay zala, Metrics = kiti, Tracing = kuthe vel lagla.
Kuthe use hoto?Prometheus + Grafana, Jaeger.

RPO / RTO

PointMahiti
Kay aahe?RPO = kiti data harvu shakto. RTO = kiti velat parat ubha.
Main GoalDisaster plan.
Ka use karaycha?Backup nasel tar data kayamcha jato.
Kasa kaam karto?Backup + Multi-region + Restore test.
Kuthe use hoto?Banking, chat history.

Chukicha Pattern — Karu Naka

Retry la Jitter nashivay saglyanni ekach veli retry kela tar Retry Storm hoto — system ajun padto. Mhanun Backoff + Jitter donhi pahije.
