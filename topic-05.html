Pratyek Sub-Topic — 5 Points

REST / gRPC / GraphQL

PointMahiti
Kay aahe?Service bolnyache marg. REST = sopa HTTP. gRPC = fast binary. GraphQL = client la pahije tech.
Main GoalBarobar protocol nivadne.
Ka use karaycha?Pratyek kamala vegla protocol.
Kasa kaam karto?REST mobile sathi, gRPC microservices sathi.
Kuthe use hoto?Public API = REST, Internal = gRPC.

Message Queue

PointMahiti
Kay aahe?Kam queue madhe thevun nantar karne.
Main GoalServices vegle karne + spike sambhalne.
Ka use karaycha?Service slow / band asel tar request harvu naye.
Kasa kaam karto?Producer → Queue → Consumer. RabbitMQ / SQS / Kafka.
Kuthe use hoto?Order → Payment → Notification.

Pub/Sub & Kafka

PointMahiti
Kay aahe?Ek event, anek jan aiktil.
Main GoalEk kam anekanna kalvne.
Ka use karaycha?Pratyekala vegla call karne avghad.
Kasa kaam karto?Topic → Partitions → Consumer Groups.
Kuthe use hoto?Feed fan-out, analytics, notification.

WebSockets

PointMahiti
Kay aahe?Donhi dishene live connection.
Main GoalLive chat / tracking.
Ka use karaycha?Polling madhe vel + kharch.
Kasa kaam karto?Ek connection ughda thev, donhikadun message.
Kuthe use hoto?WhatsApp chat, delivery tracking.

SSE / Polling

PointMahiti
Kay aahe?Server → Client ek dishene stream / Client varanvar vicharto.
Main GoalSopa live update.
Ka use karaycha?WebSocket chi garaj nasel tar.
Kasa kaam karto?SSE = live score. Polling = thodya velane vicharne.
Kuthe use hoto?Live score, notification.

Idempotency

PointMahiti
Kay aahe?Ekach request don vela aala tari ekdach parinam.
Main GoalDouble charge / double message nako.
Ka use karaycha?Retry madhe duplicate yeto.
Kasa kaam karto?Idempotency key / stable message ID vapartat.
Kuthe use hoto?Payment, chat message, queue retry.

Code — Queue Consumer (Concept)

# Producer
queue.send({"type":"order_placed","order_id":123})
# Consumer
msg = queue.receive()
process(msg)  # payment + notification
queue.ack(msg)  # zala mhanun sang
