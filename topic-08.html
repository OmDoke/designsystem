Pratyek Sub-Topic — 5 Points

Monolith

PointMahiti
Kay aahe?Sagla ekach app madhe.
Main GoalSuruvatila fast.
Ka use karaycha?Team / code motha zala tar avghad.
Kasa kaam karto?Ekach deploy.
Kuthe use hoto?Startup, chhota app.

Microservices

PointMahiti
Kay aahe?Pratyek kam vegla service.
Main GoalVegla scale / vegla deploy.
Ka use karaycha?Vegla karne = network + complexity.
Kasa kaam karto?Service Discovery + Gateway.
Kuthe use hoto?Mothi company — Amazon, Netflix.

Serverless

PointMahiti
Kay aahe?Function chalu zalyavarach paise.
Main GoalKadhitari yenarya kamasathi.
Ka use karaycha?Long / heavy kamasathi nahi.
Kasa kaam karto?Event aala ki function chalto.
Kuthe use hoto?Image resize, notification, webhook.

Event-Driven

PointMahiti
Kay aahe?Service event var react kartat, direct call nahi.
Main GoalLoose coupling.
Ka use karaycha?Order kasa thevaycha he kalayla pahije.
Kasa kaam karto?Event Bus / Kafka.
Kuthe use hoto?E-commerce, analytics.

CQRS

PointMahiti
Kay aahe?Read vegla, Write vegla rasta.
Main GoalRead / Write chi garaj vegli asel tar.
Ka use karaycha?Donhi ekatra kele tar ek slow hoto.
Kasa kaam karto?Write DB vegla, Read Model vegla.
Kuthe use hoto?Feed, dashboard, reporting.

Saga Pattern

PointMahiti
Kay aahe?Motha kam lahan steps madhe, ek fail zala tar ulta.
Main GoalDistributed transaction madhe ardha kam nako.
Ka use karaycha?2PC saglikade jamat nahi.
Kasa kaam karto?Pratyek step la Compensating action.
Kuthe use hoto?Order → Payment → Stock.

Strangler Fig

PointMahiti
Kay aahe?Juna system halu halu badalne.
Main GoalEkadam badalne dhokadayak.
Ka use karaycha?Juna band karun nava var jane.
Kasa kaam karto?Navin feature nava system var, juna halu halu kami.
Kuthe use hoto?Legacy migration.
