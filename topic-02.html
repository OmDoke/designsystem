Pratyek Sub-Topic — 5 Points

Vertical Scaling

PointMahiti
Kay aahe?Ekach machine motha karne — RAM / CPU vadhvne.
Main GoalSopa scale.
Ka use karaycha?Suruvatila.
Kasa kaam karto?Machine upgrade kartat.
Kuthe use hoto?Chhota app, suruvat.

Horizontal Scaling

PointMahiti
Kay aahe?Anakhi machines add karne.
Main GoalAmaryad scale + failover.
Ka use karaycha?Machine la limit aste, kharch vadhto.
Kasa kaam karto?LB mage servers vadhvtat.
Kuthe use hoto?Instagram, YouTube, Flipkart.

Load Balancer

PointMahiti
Kay aahe?Traffic servers madhe vatnara component.
Main GoalKonatahi server overload hou naye.
Ka use karaycha?Ek server gela tari dusra sambhalto.
Kasa kaam karto?Algorithms: Round Robin, Least Connections, Consistent Hashing.
Kuthe use hoto?Pratyek motha site.

Consistent Hashing

PointMahiti
Kay aahe?Key la hash ring var thevun server nivadne.
Main GoalServer add / kadhla tar fakt thoda data halto.
Ka use karaycha?Normal modulo madhe sagla data halto.
Kasa kaam karto?Ring var node + key — javalcha node gheto.
Kuthe use hoto?Distributed Cache, DynamoDB, Cassandra.

Rate Limiting

PointMahiti
Kay aahe?Ek user / IP kiti requests karu shakto he maryada.
Main GoalAbuse / spike pasun vachavne.
Ka use karaycha?Bot / attack ne system padu naye.
Kasa kaam karto?Token Bucket / Leaky Bucket / Sliding Window.
Kuthe use hoto?Login, OTP, API, TinyURL.

Auto Scaling

PointMahiti
Kay aahe?Load nusar servers auto vadhvne / kami karne.
Main GoalPeak la ubha, normal la kharch kami.
Ka use karaycha?Manual scaling la vel lagto.
Kasa kaam karto?CPU / QPS baghun server add / remove.
Kuthe use hoto?Flash sale, IPL, exam result.

Traffic Simulator

Users: 1000 • QPS: 100 • Servers: 2 • Cache Hit: 85% • DB Load: Low

Code — Round Robin

servers = ["s1","s2","s3"]
i = 0
def next_server():
    global i
    s = servers[i % len(servers)]
    i += 1
    return s  # s1, s2, s3, s1...
