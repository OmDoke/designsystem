News Feed

PointMahiti
Kay aahe?Post aala ki followers na feed.
Main GoalFast feed.
Ka use karaycha?Pratyek veli saglyanchi post shodhne slow.
Kasa kaam karto?Fan-out on Write (push) + Fan-out on Read (pull) hybrid. Celebrity sathi pull.
Kuthe use hoto?Instagram, Twitter.

Design Interview Flow

PointMahiti
Kay aahe?Interview madhe kasa sangaycha.
Main GoalKramvar sangne.
Ka use karaycha?Thet uttar dile tar chukta.
Kasa kaam karto?1) Requirements 2) Napkin Math 3) HLD Diagram 4) Deep Dive 5) Bottleneck + Trade-off.
Kuthe use hoto?Pratyek HLD interview.

Interview Checklist — 5 Steps

  1. Requirements: Functional + Non-functional vichar.
  2. Napkin Math: DAU → QPS → Storage → Servers.
  3. HLD: Diagram kadh — LB, Cache, DB, Queue.
  4. Deep Dive: Sharding / Cache / Queue — ekavar khol ja.
  5. Bottleneck: Kuthe adkel? Kay badalshil? Trade-off sang.
