Pratyek Sub-Topic — 5 Points

Cache-Aside (Lazy Loading)

PointMahiti
Kay aahe?App aadhi Cache baghto, miss var DB madhun gheun Cache madhe thevto.
Main GoalSaglyat common, fakt lagel tech Cache madhe.
Ka use karaycha?DB var load kami.
Kasa kaam karto?Read: Cache → miss → DB → Cache set. Write: DB update → Cache delete.
Kuthe use hoto?News feed, profile, product page.

Write-Through

PointMahiti
Kay aahe?Cache + DB donhi ekatra lihine.
Main GoalCache nehmi fresh.
Ka use karaycha?Stale data chalnar nasel tar.
Kasa kaam karto?Write donhikade, read Cache madhun.
Kuthe use hoto?Read lavkar honar asel asha data sathi.

Write-Behind

PointMahiti
Kay aahe?Aadhi Cache madhe, mag halu halu DB madhe.
Main GoalWrite khup fast.
Ka use karaycha?DB slow asel / write jast asel tar.
Kasa kaam karto?Cache madhe thev, background madhe DB la pathav.
Kuthe use hoto?Logs, analytics, counters.

Eviction — LRU / LFU / FIFO

PointMahiti
Kay aahe?Cache bharla tar konta data kadhaycha.
Main GoalMemory maryadit aste.
Ka use karaycha?Sagla thevta yet nahi.
Kasa kaam karto?LRU = saglyat juna vapralela kadha. LFU = kami vapralela kadha.
Kuthe use hoto?Redis, Memcached.

CDN Caching

PointMahiti
Kay aahe?Static content user chya javalchya server var.
Main GoalJagbhar fast + origin var load kami.
Ka use karaycha?User lamb asel tar vel lagto.
Kasa kaam karto?Edge server var image / CSS / JS thevtat.
Kuthe use hoto?YouTube thumbnail, Instagram photo, JS/CSS.

Cache Stampede

PointMahiti
Kay aahe?Ekdam saglyanni ekach miss var DB var tutun padne.
Main GoalDB crash hou naye.
Ka use karaycha?Viral post / expiry ekach veli.
Kasa kaam karto?Lock / single-flight / staggered TTL vapartat.
Kuthe use hoto?Viral URL, flash sale.

Code — Cache-Aside (Verified Pattern)

data = cache.get(key)
if data is None:  # MISS
data = db.query(key)
cache.set(key, data, ttl=300)
return data
# Write: db.update(...); cache.delete(key)

Chuk: Write var fakt Cache update karu naka — race hoto. DB update + Cache delete ha barobar pattern aahe.
