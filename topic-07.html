Pratyek Sub-Topic — 5 Points

Authentication

PointMahiti
Kay aahe?Tu kon aahes he tapasne.
Main GoalChukicha manus aat yeu naye.
Ka use karaycha?Password ekta puresa nahi.
Kasa kaam karto?JWT / OAuth / Session + MFA.
Kuthe use hoto?Login / Signup.

Authorization — RBAC

PointMahiti
Kay aahe?Tula kay karaychi parvangi.
Main GoalPratyekala sagla nako.
Ka use karaycha?Role nusar: Admin / User / Guest.
Kasa kaam karto?Private post fakt malkala disnar.
Kuthe use hoto?Admin panel, private post.

JWT / OAuth 2.0

PointMahiti
Kay aahe?Token ne login.
Main GoalServer la pratyek veli DB vicharaychi garaj nahi.
Ka use karaycha?Session pratyek server var nasel tar.
Kasa kaam karto?Login → Token → Pratyek request la token.
Kuthe use hoto?Mobile app, Google ne login.

Encryption — Transit + Rest

PointMahiti
Kay aahe?Data vatet + thevlela astana lock.
Main GoalChorla tari vachta yeu naye.
Ka use karaycha?Plain data chorla tar sagla ughda.
Kasa kaam karto?TLS (HTTPS) vatet, KMS ne at rest.
Kuthe use hoto?Password, payment, PII.

Hashing — Password

PointMahiti
Kay aahe?Password asa thev ki parat milu naye.
Main GoalPassword chorla tari kalu naye.
Ka use karaycha?Plain password thevne = gunha sarkha.
Kasa kaam karto?bcrypt / Argon2 + Salt.
Kuthe use hoto?Pratyek login system.

OWASP Top 10 / WAF

PointMahiti
Kay aahe?Saglyat common attack pasun vachavne.
Main GoalSQL Injection, XSS, CSRF sarkhe attack thambavne.
Ka use karaycha?Input var vishwas thevla tar attack.
Kasa kaam karto?Validate + Sanitise + WAF.
Kuthe use hoto?Form, search, comment, upload.

Kadhihi Karu Naka

  • Password plain madhe thevu naka.
  • Secrets / API keys code madhe / GitHub var taku naka — Vault / KMS / .env vapara.
  • JWT secret ughda thevu naka.
