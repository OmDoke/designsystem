Pratyek Sub-Topic — 5 Points

HLD — High Level Design

PointMahiti
Kay aahe?Purna system cha bird-view diagram.
Main GoalInterview madhe system samjavne.
Ka use karaycha?Konta component kuthe, data kuthe jato he dakhavayla.
Kasa kaam karto?Components + arrows ne flow dakhavtat.
Kuthe use hoto?Pratyek HLD interview chi suruvat.

LLD — Low Level Design

PointMahiti
Kay aahe?Ek component cha deep dive.
Main GoalImplementation karayla tayar hone.
Ka use karaycha?Class, function, DB schema tharvayla.
Kasa kaam karto?Class diagram, API details, schema lihitat.
Kuthe use hoto?Nantar, coding aadhi.

DNS

PointMahiti
Kay aahe?Domain nav la IP madhe badalnar system.
Main GoalUser la barobar server paryant pohochavne.
Ka use karaycha?IP lakshat thevne avghad.
Kasa kaam karto?Browser → DNS resolver → IP → request.
Kuthe use hoto?Pratyek website / app.

Latency & Throughput

PointMahiti
Kay aahe?Latency = 1 request la laglela vel. Throughput = per second kiti requests.
Main GoalSystem kiti fast / kiti load gheil he mojane.
Ka use karaycha?SLO tharvayla.
Kasa kaam karto?p95/p99 baghatat — average var vishwas nahi.
Kuthe use hoto?Saglya design madhe.

Napkin Math

PointMahiti
Kay aahe?Adajane capacity estimation — calculator shivay.
Main GoalDesign aadhi kiti server / storage lagel he kalne.
Ka use karaycha?Chukicha scale nivadla tar kharch / crash.
Kasa kaam karto?DAU → QPS → Storage → Bandwidth asha formula ne.
Kuthe use hoto?Pratyek HLD interview chi pahili 5 minute.
